# ATTENZA 🎯
### Smart Attendance Application

ATTENZA is a full-stack attendance management system designed to efficiently track, manage, and analyze attendance records. It follows a decoupled architecture with a high-performance Spring Boot 
backend and a modern React frontend.

The repository is structured into two main modules:
- backend/: Spring Boot application handling REST APIs, security, and database operations
- frontend/: React application styled with Tailwind CSS for a responsive dashboard

---

## Getting Started

### Prerequisites
- Java 17 or higher
- Node.js (v18+) and npm
- Maven (included via ./mvnw)

---

## Backend Setup (Spring Boot)

# Navigate to backend
cd backend

# Run backend server
./mvnw spring-boot:run

The backend server will run at:
http://localhost:8080

---

## Frontend Setup (React)

# Navigate to frontend
cd frontend

# Install dependencies
npm install

# Start frontend server
npm start

The frontend will be available at:
http://localhost:3000

---
